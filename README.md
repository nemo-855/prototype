# 夜航 YAKŌ

光と余白を扱う、架空のライティングアトリエのサイトです。ポインタに追従する光、文字を照らすスポット、スクロールで進む航跡を、静的な HTML / CSS / JS で動かしています。

`index.html` をブラウザで開くか、このフォルダを静的に配信してください。
